# 已冻结的决定

这些决定来自本轮实现，不是已经独立验证过的外部评审结论。

- 协议只有一个：`pa.command.v1` 命令联合、`pa.event.v1` 持久事件、`pa.ws.v1` 连接。
- 幂等键是 `(user_id, idempotency_key)`。相同规范化载荷返回原回执；不同载荷返回 409。哈希包含操作类型、目标会话、运行、审批和载荷。
- 身份来自设备令牌。请求体里的用户或频道字段不会被接受。
- 会话正文默认只对持有授权的设备可见。同一所有者的其他设备可以看到审批收件箱和 `run.outcome`，但要显式 `session.resume` 才能阅读会话。
- 每个会话同时只能有一个未结束的根运行。专员运行的 `kind` 是 `expert`，不占用这个名额。
- 演示模式和实况模式必须由命令显式选择。演示模式即使环境里有密钥也不会调用供应商。实况模式缺少密钥时直接拒绝，不会改走演示。
- 实况测试默认不跑。设置 `PA_LIVE_LLM=1` 后才允许另行执行 `pnpm test:live`。当前仓库没有附带会真正扣费的默认测试。
- 工具只有列目录、读资料和一次需要审批的演示写入。没有 shell，没有动态插件。路径会拒绝穿越和符号链接。这不是操作系统沙箱。
- 手机配对码只能在网关回环地址上签发，而且只能用一次。手机必须手动填写网关 URL。非回环绑定必须同时设置 `PA_ALLOW_UNSAFE_LAN=1`。本网关不终止 TLS。
- Electron 令牌留在主进程，并用 `safeStorage`（不可用时退回 0600 文件，这是已知限制）。渲染进程不开 Node。浏览器预览只把令牌放在内存，不写 localStorage。
- 移动端令牌进入 Expo SecureStore。前台恢复时补拉快照。没有后台连接或推送。离线时审批和取消直接失败，不排队。
- 不确定的 HTTP 结果用同一个 `commandId` 和 `idempotencyKey` 重试。

## 明确没做的生产加固

- 没有多执行器租约抢占，也没有给 LangGraph saver 增加自定义 namespace 恢复接口。
- 没有把审批续期、发现协议、推送、公网部署放进这个版本。
- 实况模型如果在工具结果写入前崩溃，重启可能再次请求模型；已完成的工具不会重做。演示路径不请求模型。
- 没有签名的桌面安装包或应用商店构建。
- “同一次逻辑写入只执行一次”只在演示账本和本地文件创建（`wx`）条件下成立。结果未知时不自动重试；这不是跨外部边界的恰好一次投递。
